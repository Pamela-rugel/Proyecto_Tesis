# Instrucciones para Claude Code

Este repositorio corresponde al proyecto de tesis:
**Sistema de Generación de Perfiles del Personal Docente y Administrativo en ESPOL para la asignación inteligente de tareas.**

## Contexto permanente

@context/00-contexto-permanente.md

## Antes de trabajar

Además del contexto permanente (importado arriba), lee los demás archivos en `/context/` en orden numérico según sea relevante para la tarea (avances, decisiones, datos, etc.).

## Notas

- `/context/` no se sube al repositorio (ver `.gitignore`) porque contiene información institucional/sensible del proyecto de tesis.
- Cuando agregues contexto nuevo relevante (decisiones tomadas, hallazgos importantes, cambios de alcance), sugiere añadirlo como un nuevo archivo numerado en `/context/` en vez de perderlo en el historial de chat.
